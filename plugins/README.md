# Plugin library

Place game-specific plugins in `BF3/`, `BF4/` or `BFH/` (Battlefield Hardline).

A copied plugin package uses `GAME/PluginName/PluginName.cs`, `.dll` or `.lua`. Keep dependencies and Lua modules inside that package directory. Use **Refresh list** in the Plugin page to discover library entries for the connected game. Plugins remain disabled until enabled explicitly.

The desktop import preference controls whether files stay at their original location or are copied into the library beside the executable. Layer clients manage the upstream library; import files on the host.
