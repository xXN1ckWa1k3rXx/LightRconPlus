Place plugins in the folder for the server's game:

BF3 - Battlefield 3
BF4 - Battlefield 4
BFH - Battlefield Hardline

Third-party plugins are not included. Keep each plugin's source, DLLs,
includes and other dependencies together. Install plugins on the Host
when using a Layer connection, then select Refresh list in the client.

See README.md in this folder and docs/PLUGINS.md for details.
